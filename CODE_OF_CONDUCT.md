# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct.

We expect all contributors, maintainers, and community members to follow it in any project space — issues, pull requests, discussions, chat channels, and any project-related event.

## Reporting

If you observe behaviour that violates this Code of Conduct, please open a confidential report by emailing the project maintainers. We will respond as quickly as possible.

Until a dedicated contact address is set up (see [docs/IDEAS.md](docs/IDEAS.md) for the community-channels item), contact a maintainer directly via GitHub.

## Enforcement

Maintainers are responsible for clarifying the standards of acceptable behaviour and will take appropriate and fair corrective action in response to any behaviour they deem inappropriate. The full enforcement guidelines are defined in the linked Contributor Covenant text.
